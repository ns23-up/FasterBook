# Fasterbook — инструкции для Claude Code

## Что за проект
Fasterbook — веб-сервис быстрого чтения книг: на экране показывается одно слово по центру, слова сменяются с заданной скоростью. Интерфейс полностью на русском языке.

## Пользователь
Начинающий разработчик. Знает основы, но просит помощь с архитектурой и объяснением кода. Не усложняй без необходимости. Объясняй простыми словами, что и зачем делаешь.

## Стек
- Next.js (App Router), React, TypeScript (strict), Tailwind CSS v4.
- Запуск: `npm install`, затем `npm run dev` (http://localhost:3000).
- Проверки: `npm run typecheck`, `npm run build`.
- Supabase Auth подключён (вход по почте и паролю). PostgreSQL используется для статистики чтения и для книг вошедших пользователей (таблица `books` + закрытое хранилище Storage `book-texts`, миграция `supabase/migrations/20261101120000_books.sql`, перенос разрешён владельцем). У гостей книги в браузере (IndexedDB). Настройки — в браузере. Избранное: колонка `books.is_favorite` и таблица `quotes` (миграция `20261102120000_favorites.sql`).

## Структура
- `app/(app)/` — разделы с общей оболочкой: Главная, Мои книги, Избранное, Друзья, Настройки.
- `app/reader/[bookId]/` — читалка на весь экран.
- `components/` — переиспользуемые компоненты.
- `lib/reader.ts` — логика читалки (разбиение на слова, кадры по 1–3 слова с приклеенными предлогами, задержки). Без React. Позиция в книге — номер слова, а не кадра.
- `lib/settings.ts` — настройки в localStorage браузера.

## Важные правила
1. Не выдавай выдуманные данные за реальные. Демо-данных в проекте больше нет: показывай только настоящие данные пользователя или честное «пусто» / «—». Не придумывай цифры.
2. Не создавай новые таблицы, не переноси данные в базу и не подключай вход через Google без явного разрешения владельца. Любые изменения базы — только SQL-файлами в `supabase/migrations/` с пояснением; применяет их владелец вручную в Supabase SQL Editor. Claude базу сам не меняет.
3. Не клади секреты, ключи и `.env` в код или в репозиторий.
4. Не переписывай уже работающие части без необходимости. Меняй минимально нужное.
5. Все надписи интерфейса — на русском языке.
6. После изменений запускай `npm run typecheck` и `npm run build`, исправляй ошибки до того, как сообщишь о готовности.
7. Не отправляй изменения (`git push`) и не создавай коммиты без явной просьбы владельца.

## Этапы разработки
- Этап 0 (каркас, навигация): сделан.
- Этап 1 (читалка, одно слово по центру): в основном сделан.
- Режим «Читать целиком»: `components/PageReader.tsx` (весь текст по абзацам, прокрутка, позиция — первое видимое слово), переключатель в `ReaderClient.tsx`. Настройки `readMode` и `pageFontSize` в `lib/settings.ts`. Позиция общая для обоих режимов; время чтения считается, пока текст прокручивают (90 секунд без прокрутки — пауза). Караоке: кнопка ▶ в этом режиме подсвечивает кадры по очереди на общем таймере скорочтения (та же скорость и «слов за раз»), текст сам прокручивается; колёсико или палец ставят на паузу. Окно цитат берёт фон из настроек.
- Этап 2 (загрузка TXT в IndexedDB, сохранение позиции): сделан. Файлы: `lib/text-file.ts` (чтение TXT, DOCX и RTF — формат определяется по содержимому, кодировки UTF-8/windows-1251/UTF-16), `lib/docx.ts` (текст из Word .docx через библиотеку `fflate`; старый двоичный .doc не поддерживается), `lib/rtf.ts` (RTF, в том числе .doc-файлы, которые на самом деле RTF), `lib/books-db.ts` (IndexedDB: таблицы `books` и `texts`), `components/StoredReader.tsx` (открывает свою книгу в читалке). Главная пока показывает только демо-книги. Книги в аккаунте: `lib/cloud-books.ts` (Supabase), `lib/library.ts` (общий интерфейс Library: аккаунт или браузер, перенос книг из браузера в аккаунт), `components/useLibrary.ts` (выбирает хранилище по входу).
- Избранное (этап 1 — любимые книги и цитаты): сделано. `lib/quotes.ts` (цитаты, только в аккаунте), `sentenceAt` в `lib/reader.ts` (предложение вокруг слова), `components/FavoritesClient.tsx`, сердечко в `BooksClient.tsx`, кнопка цитаты в читалке открывает `components/QuotePicker.tsx` (прочитанный текст до текущего места, 500 слов + «Показать раньше» до 2000; цитата выбирается нажатием на первое и последнее слово). Любимые книги работают и у гостя. Заметки, «Интересные места», «Список на потом» — заглушки.
- Друзья: код сделан, миграция `supabase/migrations/20261103120000_friends.sql`. Заявка + подтверждение; поиск по короткому числовому ID (`profiles.public_id`, с 100001); друзья видят никнейм, серию дней и книгу за 14 дней (можно выключить). Почту никто не видит. Файлы: `lib/profiles.ts`, `lib/friends.ts`, `components/FriendsClient.tsx`. Никнейм вводится при регистрации (`user_metadata.nickname`), профиль создаётся при первом открытии «Друзей». «Что читаю» обновляет `StoredReader`. «Друзья онлайн»: миграция `20261104120000_friends_online.sql`, `components/PresencePing.tsx` (отметка раз в 2 минуты), онлайн = отметка за 5 минут.
- Демо-данные удалены (`lib/demo-data.ts`, `DemoBadge`). Главная (`components/HomeClient.tsx`) показывает только настоящие книги, серию и друзей.
- Аккаунты (Supabase Auth, только почта и пароль): сделаны. `lib/supabase/` (config, client, server, middleware, errors), `middleware.ts` (обновление сессии через getUser), `app/(auth)/` (login, register, forgot-password, reset-password), `app/auth/callback/route.ts` (ссылки из писем), `components/AuthProvider.tsx` (useAuth), `components/auth/`. Ключи — в `.env.local` (пример в `.env.example`). Без ключей сайт работает как раньше.
- Статистика чтения (серия дней, время, слова, завершённые книги, календарь): код сделан, нужна SQL-миграция `supabase/migrations/20261031120000_reading_stats.sql` (инструкция в `supabase/README.md`). Файлы: `lib/stats.ts`, `lib/reading-tracker.ts` (учёт времени без React), `components/useReadingTracker.ts`, `components/stats/`, `app/(app)/stats/`. Считается только для вошедших и только пока идёт чтение при видимой вкладке.
- Далее: Мои книги с поиском и сортировкой, настройки и Focus Mode, статистика, избранное и цитаты, аккаунты Supabase, профиль, друзья, PWA.
