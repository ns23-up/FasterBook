# Fasterbook — инструкции для Claude Code

## Что за проект
Fasterbook — веб-сервис быстрого чтения книг: на экране показывается одно слово по центру, слова сменяются с заданной скоростью. Интерфейс полностью на русском языке.

## Пользователь
Начинающий разработчик. Знает основы, но просит помощь с архитектурой и объяснением кода. Не усложняй без необходимости. Объясняй простыми словами, что и зачем делаешь.

## Стек
- Next.js (App Router), React, TypeScript (strict), Tailwind CSS v4.
- Запуск: `npm install`, затем `npm run dev` (http://localhost:3000).
- Проверки: `npm run typecheck`, `npm run build`.
- В будущем: Supabase и PostgreSQL. Пока НЕ подключать.

## Дизайн
- Основной фон: #311E16. Акцент: #E97571. Дополнительно: тёмный коричневый, графитовый, тёплый кремовый.
- Минимум неона, без сильного свечения и градиентов.
- Цвета задаются токенами в `app/globals.css` (`bg-ink`, `text-accent`, `text-cream` и т.д.). Не вставляй цвета напрямую в компоненты.
- Адаптив: ПК — боковая панель слева; телефон — нижняя навигация.
- Логотип: открытая книга с линиями движения, акцентным цветом.

## Структура
- `app/(app)/` — разделы с общей оболочкой: Главная, Мои книги, Избранное, Друзья, Настройки.
- `app/reader/[bookId]/` — читалка на весь экран.
- `components/` — переиспользуемые компоненты.
- `lib/reader.ts` — логика читалки (разбиение на слова, кадры по 1–3 слова с приклеенными предлогами, задержки). Без React. Позиция в книге — номер слова, а не кадра.
- `lib/settings.ts` — настройки в localStorage браузера.
- `lib/demo-data.ts` — демонстрационные данные.

## Важные правила
1. Не выдавай демо-данные за реальные. Всё из `lib/demo-data.ts` помечается метке «Демо» (компонент `DemoBadge`). Статистика, серия дней и рекомендации пока заглушки — не придумывай для них цифры.
2. Не подключай базу данных, Supabase и авторизацию без явного разрешения владельца.
3. Не клади секреты, ключи и `.env` в код или в репозиторий.
4. Не переписывай уже работающие части без необходимости. Меняй минимально нужное.
5. Все надписи интерфейса — на русском языке.
6. После изменений запускай `npm run typecheck` и `npm run build`, исправляй ошибки до того, как сообщишь о готовности.
7. Не отправляй изменения (`git push`) и не создавай коммиты без явной просьбы владельца.

## Этапы разработки
- Этап 0 (каркас, навигация): сделан.
- Этап 1 (читалка, одно слово по центру): в основном сделан.
- Этап 2 (загрузка TXT в IndexedDB, сохранение позиции): сделан. Файлы: `lib/text-file.ts` (чтение TXT, кодировки UTF-8/windows-1251/UTF-16), `lib/books-db.ts` (IndexedDB: таблицы `books` и `texts`), `components/StoredReader.tsx` (открывает свою книгу в читалке).
