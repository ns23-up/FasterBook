# Fasterbook — прототип, этап 0–1

Сервис быстрого чтения: одно слово в центре экрана.

## Запуск локально

Нужен Node.js 20.9 или новее (рекомендуется 22 LTS).

```bash
cd fasterbook
npm install
npm run dev
```

Откройте в браузере адрес **http://localhost:3000**.

Проверки:

```bash
npm run typecheck   # проверка типов TypeScript
npm run build       # продакшен-сборка
npm run start       # запуск собранной версии
```

## Что есть в прототипе

- **Главная:** приветствие, «Продолжить чтение», статистика (с пометкой, что это заглушки), избранное, друзья.
- **Мои книги:** поиск и сортировка по демо-списку. Кнопка загрузки пока неактивна (этап 2).
- **Избранное:** демо-книги и демо-цитаты.
- **Друзья:** демо-профили, подписка работает в памяти страницы.
- **Настройки:** скорость и шрифт, сохраняются в `localStorage` этого браузера.
- **Читалка:** одно слово по центру, пауза, переход вперёд и назад, полоса позиции, скорость, шрифт, режим фокуса, полный экран.
  - Клавиши: пробел — пауза, стрелки ← → — слово, ↑ ↓ — скорость, Esc — выйти из фокуса.

## Что намеренно не сделано

- База данных, Supabase, вход в аккаунт (по плану, это этапы 2 и 7).
- Загрузка файлов TXT и EPUB (этап 2).
- Сохранение позиции чтения между сессиями (этап 2).
- Реальная статистика и серия дней (этап 5).

Все книги, цитаты и друзья в `lib/demo-data.ts` выдуманы и помечены как «Демо».

## Структура проекта

```
app/
  (app)/            разделы с боковой панелью и нижней навигацией
    layout.tsx      общая оболочка
    page.tsx        Главная
    books/          Мои книги
    favorites/      Избранное
    friends/        Друзья
    settings/       Настройки
  reader/[bookId]/  читалка на весь экран
  layout.tsx        корневой layout, язык ru, метаданные
  globals.css       цвета бренда (#311E16, #E97571 и др.)
  icon.svg          иконка приложения
components/         переиспользуемые куски интерфейса
lib/
  reader.ts         логика читалки: разбиение на слова, задержки
  settings.ts       настройки в браузере
  navigation.ts     список разделов для меню
  demo-data.ts      демонстрационные данные (помечены как демо)
```

Цвета задаются один раз в `app/globals.css` и используются как `bg-ink`, `text-accent` и т.д.
